# WHAT IS SERVER-CLIENT MODEL?
The Client-Server Model is a network architecture in which a client sends a request to a server, 
and the server processes the request and sends back a response.

[*] Client-Server Model ek network architecture hai jisme client server ko request bhejta hai, aur server us request 
ko process karke client ko response bhejta hai.
# EXAMPLE-:

CLIENT → REQUEST → SERVER

CLIENT ← RESPONSE ← SERVER
