# what is protocol ?
A network protocol is a set of rules and standards that define how devices communicate and exchange data over a network.

[*] Protocol rules aur standards ka ek set hota hai jo decide karta hai ki network par devices ek-dusre ke saath data kaise communicate aur exchange karenge.

# Protocol kya decide karta hai?

Protocol decide kar sakta hai:

Data ka format kya hoga?

Data kaise send hoga?

Data kaise receive hoga?

Error hone par kya hoga?

Connection kaise establish hoga?

Communication secure/encrypted hogi ya nahi?

# Cybersecurity mein Protocol kyun important hai?

SOC Analyst ko network traffic investigate karte waqt protocols ko identify karna padta hai.
