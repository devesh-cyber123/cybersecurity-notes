# TYPES OF TOPOLOGY?
# 1.Star Topology-:
Star topology is a network topology in which all devices are connected to a central device such as a switch or hub.

[*] Is topology mein saare devices ek central switch ya hub se connected hote hain.

# EXAMPLE-: 
(Office ke computers ek central switch se connected hain.)

# IMPORTENT POINT-:
Agar ek PC ki cable fail ho jaaye → baaki network generally chalta rahega.
Agar central switch fail ho jaaye → us switch se connected devices ka communication affect hoga.

# 2. Bus Topology-:
Bus topology is a network topology in which all devices are connected to a single main communication cable called a backbone.

[*] Ismein saare devices ek main cable (backbone) se connected hote hain.

# 3. RING TOPOLOGY-:
Ring topology is a network topology in which each device is connected to two other devices, forming a circular path.

[*] Ismein devices circle/ring shape mein connected hote hain.
      
 Har device apne neighboring devices se connected hota hai.

# 4. MESH TOPOLOGY-:
Mesh topology is a network topology in which devices have multiple connections or paths between them.

[*] Ismein devices ke beech multiple connections/paths hote hain.
# Main advantages-:
Agar ek connection fail ho jaaye, to alternative path available ho sakta hai.
Isliye mesh topology mein redundancy aur reliability high hoti hai.

# 5. TREE TOPOLOGY-:
Tree topology is a hierarchical network topology in which devices are organized in levels, forming a tree-like structure.

[*] Ismein network hierarchical/tree structure mein arranged hota hai.

# 6. HYBRID TOPOLOGY-:
Hybrid topology is a network topology that combines two or more different types of network topologies.

[*] Jab do ya do se zyada topologies ko combine kiya jata hai, use Hybrid Topology kehte hain.
