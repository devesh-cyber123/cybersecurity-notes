# what is point-to-point?
A point to point network is a direct communication link between two devices where travels from one end point
 to the other without passing through any intermediate devices.

 [*] point to point network main do devices ke beech direct connection hota hai.isme data seedha ek device 
se doosre device tak jata hai beech mai koi or device nhi hota.
# EXAMPLE-:
ROUTER A <------>ROUTER B
COMPUTER A<------> COMPUTER B
