# what is /boot ?

# /boot — Boot Files

/boot contains files required for booting the Linux system.

[*] Linux system ko boot/start karne ke liye required files /boot mein hoti hain.

# Example:

/boot

├── vmlinuz

├── initrd

└── grub/

# Cybersecurity

Boot-related tampering system integrity ke liye serious issue ho sakta hai.
