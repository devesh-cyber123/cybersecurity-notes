# what is /home directories ?
/home - user directories

/home contains the personal directories of normal users.

[*] Normal users ki personal files aur directories /home mein hoti hain.

# example-:

/home/devesh/

├── Documents

├── Downloads

├── Pictures

└── Desktop

# cybersecurity mai importance

User ki suspicious files, downloaded malware, scripts ya compromised files ko investigate karte waqt /home important hota hai.
