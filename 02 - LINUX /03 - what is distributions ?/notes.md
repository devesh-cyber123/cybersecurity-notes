# what is distributions ?
A Linux distribution is a complete operating system built around the Linux kernel, combined with system utilities, 
libraries, package managers, applications, and configuration tools.

[*] Linux Distribution ek complete operating system package hota hai jo Linux Kernel ke upar bana hota hai. Isme kernel ke saath:

System utilities

Libraries

Package manager

Shell

Applications
