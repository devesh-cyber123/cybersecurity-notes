# what is kernel ?
The kernel is the core component of an operating system that manages hardware resources and provides an interface between applications and hardware.

[*] Kernel operating system ka core/heart hota hai. Ye applications aur hardware ke beech 
communication karwata hai aur system resources ko manage karta hai.
